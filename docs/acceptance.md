# 阶段 5 验收总结

> 2026-11-23 ｜ R1-A7-D 左臂 + 辐射检测模块（126×126×190 mm / Ø47 / 1.5 kg）
> 结论：**需求的核心部分（探头端面在竖直平面内上下扫 50 cm）在真机上成立**，
> 部分指标受硬件限制或尚未测。

## 1. 需求对照

| 需求 | 指标 | 真机实测 | 结论 |
|---|---|---|---|
| 探头端面在竖直平面内上下移动 | 行程 50 cm | **496.5 mm** | ✅ |
| 直线度（相对拟合直线） | ≤20 mm | **4.8 mm**（RMS 1.7） | ✅ |
| 探头轴线与法向夹角 | ≤10° | **5.8°**（均值 3.2） | ✅ |
| 探头离箱面 | 设计 200 mm | **199.9 mm** | ✅ |
| 重复性（3 趟） | 散差 ≤30 mm | **2.9 mm** | ✅ |
| 绝对位置 | ≤100 mm | 未测（用户判定无需） | — |
| 扫描速度 | 0.02–0.05 m/s | **0.014 m/s** | ⚠️ 偏慢 |
| 腕部力矩 | ≤90% 额定 | 峰值 **9.9 / 10 N·m** | ⚠️ 贴限 |
| 控制频率 | ~500 Hz | 309–350 Hz（虚拟机限制） | ⚠️ |

## 2. 真机验证过的事

| 项 | 实测 |
|---|---|
| DDS 链路 | `ens33` / domain 0，680–713 Hz，坏 CRC 0，`mode_machine=11` |
| 槽位归属 | 14/14 活着（左臂 7 控制 + 右臂 7 保持），腰 yaw 在槽位 13 |
| 关节方向 | 7 个左臂关节各 ±4° 探测，方向全部与 URDF 一致 |
| 接管 | 14 槽位按实测角按住 7 s，零位移；随后单关节 ±10° 跟踪 0.3° |
| 完整扫描 | 25 趟以上，全部 `complete`，无保护误触发（除已知的两次真问题） |
| 重复性 | 三轮散差 2.9 mm，三轮直线度完全一致 |

## 3. 真机上发现的、与资料不符的地方（都是靠上机才发现的）

1. **左腕 pitch 是 ±43° 机械硬限位**，URDF 写 ±92.5°。这是整个项目影响最大的发现：
   它直接决定了站位（0.64 m / 伸出 0.44 m）和扫描速度。
2. **`tau_est` 基本是空的**（0.02–0.11 N·m）。所以"实测力矩"这个保护在真机上形同虚设，
   真正起作用的是"预计力矩"那一项。
3. **槽位 12 不是关节**（报 86 rad）。已给 `scan.py` 加闸门：保持关节实测角超出 ±π 直接拒启。
4. **虚拟机调度会出现 46–77 ms 的停顿**。已改成两级判据（单次 150 ms / 10 秒内 5 次 50 ms）。

## 4. 现在怎么用

```bash
# 一条命令：现场检查 → 通道检查 → 抓取确认 → 扫描 → 汇总
bash run_real.sh                 # 1 趟（上下各一次，约 86 s）
PASSES=3 bash run_real.sh        # 3 趟
```

前置：机器人上电、遥控器进入低层（Q5）、人已就位、急停在手。

## 5. 还没做的

| 项 | 卡在哪 |
|---|---|
| 辐射联调（5.8） | 需要探测仪的接口：是匀速扫还是定点停留（Q4）、采集怎么和动作对齐（TTL/串口/软件触发） |
| 绝对定位精度 | 用户判定只需"肉眼差不多"，未用卷尺/激光复核 |
| 探头质量/质心核对 | 用户决定不再核对，仍按 1.5 kg / 95 mm 估值 |
| 扫多趟的辐射累积 | 需要辐射端的计数判据 |
