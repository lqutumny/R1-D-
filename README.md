# R1-D 左臂扫描与立柱联动

| 目录 | 用途 |
| --- | --- |
| [r1d_radiate_scan_fast_stable](./r1d_radiate_scan_fast_stable/) | 左臂独立扫描，按当前姿态规划到 50 cm 扫描线，扫描后竖直收纳 |
| [r1d_chassis](./r1d_chassis/) | 左臂与升降柱联动扫描，自动归位后执行立柱 DDS 目标 400 → 800 → 400 mm |

两套代码可独立使用，运行环境及依赖见各自项目的说明。仓库包含运行需要的 MuJoCo 场景、关节配置和机器人网格；现场数据和运行输出留在部署机器上，不上传本仓库。

## 当前进度（2026-11-26）

左侧朝箱的 600 mm 左臂平顺扫描已完成固定立柱仿真和真机验证，当前联动版可读取立柱高度、把任意可信起始高度自动调整到 400 mm，再执行手臂 600 mm 与立柱 400→800→400 mm 同向扫描，形成约 1 m 的单列实际覆盖，最后回到 400 mm 并收纳手臂；最新两轮真机均完成自动归位和完整上下扫，其中一轮完整收纳并正常结束，另一轮在收纳阶段因 DDS 高度与速度反馈短暂达到 201 ms、刚超过 200 ms 保护阈值而安全停止，因此主体功能已能简单稳定运行，下一步重点是提高瞬时反馈超时情况下的连续运行稳定性。

## 左臂独立仿真

```bash
cd r1d_radiate_scan_fast_stable
MUJOCO_GL=glfw bash run_demo.sh
```

## 左臂与立柱联动仿真

从本仓库根目录执行：

```bash
cd r1d_chassis
MUJOCO_GL=glfw bash run_sync_sim.sh
```

真机只读预检与启动命令见[联动项目说明](./r1d_chassis/README.md#真机联动入口)。
